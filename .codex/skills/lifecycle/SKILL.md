# 生命周期

先读 [F07 功能说明](../../../docs/features/f07-lifecycle.md)、架构 §13.6、plan/progress 以及 coding/tdd/data-foundation/durable-tasks/private-chat/companion-personas/model-runtime。沿用 plan §7 已确认的 HTTP、Web、任务/模型与进程恢复边界。

- 删除选中消息、重置实例、删除实例是不同命令。重置保留身份与初始种子、更新代次，从新会话继续；删除实例擦除私有状态，保留共同原文和最小历史身份，其他实例及模板不级联清空。
- 限制、版本/代次、最小操作日志、目标和清理任务同事务生效；锁顺序模型配置头 → 调度头 → 会话/实例。网络访问不得持有事务。
- 读取、派发、结果采用和发布都检查当前限制，不能只在 worker 起点检查。已删除原文不得再次进入上下文，旧人格版本不得跨代次读取，删除实例不能再成为新消息的处理接收方。
- 重置恢复保存的首次人格与初始明确约束，不能使用已变更模板或后续成长覆盖。私有上下文可清除；已发布回复的源身份图必须独立保留，确保之后删原文仍能追溯依赖。
- 清理进度与每批变更同事务。协议版本和阶段顺序影响恢复，后续模块新增阶段须保留在途旧协议解释，不能原地重排。向量、文件等外部步骤用幂等动作和持久检查点接入。
- 暂停、失败、取消任务都不解除限制。显式恢复沿用操作 ID/范围/阶段，新建执行任务且保留旧尝试，旧 worker 不能提交。额外的一个部署级清理位置只运行数据库清理，不提高模型并发或额度。
- 清除正文、候选、任务输入和私有状态，不把它们复制进日志。模型调用尝试及用户级/全局用量保留，迟到可信计量可结算，迟到正文不能恢复。无来源的独立证据不能凭猜测删除。
- 网页先显示确切范围再确认。跨窗口内容版本变化立即清除旧缓存及在途读取，清理期间禁读，旧代次会话只读。离线客户端重连需重新核对。
- 已发布 0000–0005 迁移不可改写；后续只追加。0005 回填既有 F06 上下文的来源图，维护恢复验证必须覆盖旧数据。
- F23 前没有旧备份导入；主库日志不等于独立恢复围栏。不要声称 MySQL 保留卷重启验证已经完成历史备份防复活。

修改后运行真实隔离 MySQL 与公共命令测试、相关模型/任务回归、浏览器多窗口、Docker 保留卷升级/恢复，以及格式、lint、类型和构建。`verify:f07` 只创建并清理自己的验收范围，不直接调用模型；F08 自动整理可触发 test，启用真实记忆模型时脚本须提前退出。更新说明、计划/进度，按用户授权提交推送 dev，交付当前功能后停下供 review。

F08 已接入批量记忆整理。涉及记忆来源、processing_ranges、后台并发或生命周期派生清理时，同时阅读 [memory-organization](../memory-organization/SKILL.md)。记忆和清理各有独立执行位置；旧 v1 生命周期阶段保留，新增操作使用 v2。0006 交付后同样不可改写。

F09 已接入记忆检索、跨私聊来源及 Qdrant 索引。涉及上下文、版本、后台调度或删除恢复时，同时阅读 [memory-retrieval](../memory-retrieval/SKILL.md)，保留固定输入与无正文来源图。

头像增加 v4 清理协议，在原 v3 末尾追加 avatar_files，v1–v3 解释不变。删除实例先持久禁止读取和新上传，事务外幂等删除目录，复查租约/检查点后清除引用并推进；重置实例保留头像。0008 已交付后不可改写；参见 [头像说明](../../../docs/features/starry-chat-avatars.md)。
