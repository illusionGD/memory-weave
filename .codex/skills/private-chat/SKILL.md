# 私聊维护

先读 `docs/features/f06-private-chat.md`、架构 M02/M03/M09 和当前 contracts；同时遵循 coding、tdd、data-foundation、model-runtime、durable-tasks、companion-personas。公共测试边界沿用 plan §7，不需重复确认。

- 用户原文发布、旧轮失效、当前轮次与任务创建同事务提交，先保存后处理。F02 管理写入口不能旁路聊天协议，查询原文仍可复用。
- 流式候选不等于发言。只显示正式提交的不可变片段，来源为 model_output；chat_segments 保存引用，页面合并气泡，不复制另一份权威原文。
- 发布锁顺序是模型配置头 → 调度头 → 会话/实例。取消模型调用、换轮、代次/人格版本变化、失效租约都应阻止下一片段。不得在持有调度锁后反向取得模型配置锁，也不得持锁访问外部模型或 SSE。
- 模型请求使用 chat run/task ID，恢复不换身份。已成功候选校验已有发布前缀后补剩余文字；未知调用不自动重发。失败收尾不能发布未提交缓冲。
- 当前人格 document 优先；没有 document 的当前原稿版本可供聊天使用，不自动整理或把旧初始人生重新注入后续人格。保留当前必要原文和明确约束；预算不足返回明确原因，旧历史按交流组省略并记录边界。
- 上下文来源固定精确消息/版本/人格引用，原文按当前代次、成员与可见区间检查；实例取得正文与用户终端送达分开。只声明实际 Web 能力，没有工具、记忆检索或自主成长时不得虚构。
- SSE 复用正式原文序号，每批最多 50 条；状态来自持久任务。慢客户端需要背压，断开不取消生成；会话失效需关闭连接。连接数、轮询与片段参数集中配置并有边界。
- 终端送达按 messageId/contentVersion/terminalId 自然键幂等，不以最大游标跨越漏收消息，也不称为人类已读。查询和事件发送本身无送达副作用。
- Web 纯文本展示，消息身份去重、失败保留原文和命令身份、切页丢弃迟到响应，历史分页和实时页有界。不在 localStorage 保存私人对话。
- 流式供应商需显式登记能力；不支持时整段返回。兼容协议处理跨字节 UTF-8、帧限制、结束标志和未知用量；不得把非流式响应分片后宣称真实流式。test adapter 明确仅验证链路。
- 0000–0004 发布后不可改写；涉及新字段追加迁移。验证真实 MySQL、跨进程迟到输出、强杀恢复、SSE 重连、模型取消缓冲、浏览器断网去重、Docker 升级/保留卷恢复。任务完成同步文档并提交推送授权 dev，停在当前功能供 review。

F07 已接入生命周期限制与清理。涉及消息来源、实例代次、任务恢复、模型候选或人格版本的改动，需同时阅读 [lifecycle](../lifecycle/SKILL.md)，接入读取/派发/提交检查及分批清理协议，保留共享原文和全局计量边界。
