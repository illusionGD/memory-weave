# F10 记忆浏览

先读 [功能说明](../../../docs/features/f10-memory-explorer.md)、plan/progress 与 coding/tdd/memory-organization/memory-retrieval/lifecycle。产品范围已确认：按记下时间排序并保留经历描述，图谱追溯记忆/原文/修订/冲突，只读浏览，纠错仍通过聊天自主整理。

- 入口只放 `apps/admin`，不混入星空聊天。契约在 contracts，HTTP 客户端在 browser-client；后端、前端共用数字响应码和中文属性说明。
- 默认同用户、同伴侣、同代次私聊汇总；群聊必须显式限定会话。任何列表、分页、图谱节点和来源都重新验证当前范围与生命周期，游标和读取指纹不是权限凭据。
- 时间线按版本 `createdAt` 和稳定 ID 排序；筛选范围参与游标身份，保持上界。模糊经历时间原样显示，历史状态不随当前分歧一起覆盖。
- 图谱只解释真实持久关系，`previousVersionId` 才是修订，普通依赖与整理上下文分别标记。不能用模型补造连线、复制全图或把推断当成事实。双向展开同一关系共用边 ID。
- 每次只展开一层，LIMITS 集中维护；列表、会话、历史和证据独立分页，画布有总上限和键盘文本替代。Cytoscape 按需加载、无持续动画，卸载释放资源。
- 浏览验证只查已显示引用的状态字段。来源变化、重置、删除、断线、范围切换必须清除正文/引文/图谱并拒绝迟到响应；后台页恢复先验证，首次初始化被隐藏打断后要重新读取。不得持久缓存原文。
- 已发布迁移 0000–0009 不改写，新增结构追加。SQL 优化要记录实际语料、查询计划和端到端延迟；小样本不代表目标云服务器容量。
- 公共 HTTP 测试 + 真实 MySQL 验证筛选、稳定分页、图语义和生命周期；`pnpm verify:f10` 在随机隔离库经模型协议 fixture 生成非空记忆并跑桌面/手机流程，不能声称验证真实模型理解。测试仅清理自己创建的库。
- 交付前更新说明与进度，验证保留卷升级/重启、来源和人格不变；按已有授权提交推送 dev，然后停在当前功能供 review。下一大功能先走 to-tickets。
