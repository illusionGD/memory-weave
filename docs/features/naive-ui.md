# Naive UI 双端组件

聊天端与管理后台统一使用 Naive UI 2.45.3 的通用控件，两端仍独立构建与部署。聊天端保留星空、月亮、聊天气泡和扁平按钮；后台使用浅色工作区、深色导航和数据表格。

## 覆盖范围

- 两端登录、表单、输入框、按钮、状态标签、持续错误提示与折叠资料。
- 后台导航、伴侣表格、创建与详情、人设模板、运行状态和清理记录。
- 记忆列表、时间线、筛选与日期选择、来源详情、图谱周边操作；图谱继续使用 Cytoscape。
- 聊天列表、输入与发送、资料、个人设置、只读回忆和头像。
- 删除、重置改为页面内确认弹窗；取消不发送命令，离开目标页面或目标版本变化后不能继续提交旧操作。

## 实现约定

依赖版本在 `pnpm-workspace.yaml` catalog 统一维护。每个应用自己的 `App.vue` 接入中文 `NConfigProvider`、`NMessageProvider`、`NDialogProvider`，主题集中在各自 `src/assets/styles/naive-theme.ts`。组件按需导入，contracts 与 browser-client 不依赖 UI 框架。

`UiLink` 通过 RouterLink 的公开插槽与 NButton 的 `tag="a"` 保留真实链接和路由导航。表单按钮使用 `attr-type="submit"`，字段关联通过 NFormItem 的 `label-props` 和输入组件的 `input-props` 落到真实输入元素。业务规则继续使用 contracts 的 Zod 校验。

头像通过 NUpload 选图并本地预览，点击保存后仍调用现有二进制 PUT；选图本身不上传。NAvatar 保留同源图片读取、默认月亮和加载失败回退。折叠标题使用可键盘操作的按钮，并暴露展开状态。

记忆日期按浏览器本地时间输入，提交时转为 UTC；清空筛选会移除请求中的对应条件。列表保留原服务端游标，不增加虚假的总页数。SSE、聊天滚动、输入法回车、草稿、停止回复、消息版本和来源失效校验继续使用原业务实现。

## 本地 review

安装依赖后启动既有开发服务，在聊天端与 `/admin/` 分别检查：

1. 登录、退出，错误提示与键盘焦点。
2. 创建伴侣、查看人设与历史版本，用 Tab、Enter、Space 展开资料。
3. 选择头像但不保存、保存头像、恢复默认；两端都能看到图片。
4. 聊天输入中文，Enter 发送、Shift+Enter 换行；断线后的草稿仍保留。
5. 删除消息先取消，刷新后内容仍在；确认删除后查看清理结果。
6. 后台筛选记忆、选择与清空时间、查看来源与图谱；删除来源后旧内容不能继续显示。
7. 手机宽度下查看导航、长名称、表格、弹窗与聊天滚动。

UI 替换不改变数据库结构，不需要 SQL 迁移。同批 Redis 鉴权调整的启动配置请按鉴权功能说明执行。

## 验证记录

比较基线为 `3ac3f3b`。Node 22.23.4 下，全工程格式、ESLint、类型检查与生产构建通过；新后端与真实 MySQL / Qdrant / Redis 配合下，桌面和手机 Chromium 共 30 条浏览器流程通过，未捕获脚本异常或 CSP 违规。已检查聊天、头像、运行状态、时间线与图谱截图。另在 320×720 CSS px 下完成后台创建/键盘折叠与聊天发送两条补查，页面无横向溢出，聊天输入区保持在视口内。

浏览器入口先执行 Zod `jitless` 配置，再加载业务 schema，避免动态代码探测触发 CSP；服务器安全策略保持原值。浏览器回归还修复了后台导航撑宽手机视口、默认头像插槽遮挡图片及状态更新误关确认弹窗的问题。
