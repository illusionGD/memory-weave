# F10 查询性能记录

2026-10-31，托管开发机，Node 22.23.4、MySQL 8.4.9 容器。以公开 HTTP 生成固定语料并查询，不使用付费模型。复现命令、限制及最终汇总见 [F10 说明](../../docs/features/f10-memory-explorer.md)。

- `preliminary.json`：补正式迁移前的探索测量；状态核对尚未缩小 SQL 投影，图谱记录查询尚未显式加入版本 owner 条件。
- `final.json`：正式查询实现及 `0009` 迁移下的测量。脚本只在其随机隔离库内移除/恢复两个新索引，保存相同语料的对照。单请求每类 30 次，4 并发列表 32 次；各轮预热一次。

语料为 1,000 条记忆、1,000 个版本、134 条原文，一条记忆额外合并 50 次证据。EXPLAIN 仅对应排序、前置版本定位子查询；并非整个接口联合查询。RSS 仅为 Node 进程峰值，不包含数据库和向量服务。

共享环境和索引 DDL 后的统计/缓存状态会影响结果。初测的索引后时间线 P95 为 1,150 ms；最终无新索引列表的 P95 为 1,009 ms，而同轮后续 4 并发列表恢复至约 222 ms。保留这些波动，不把有限采样解释为延迟上限，也不将前后差异全部归因于索引。尚未测十万级语料、真实模型提取质量或 2 核 4 GB 目标主机容量。
